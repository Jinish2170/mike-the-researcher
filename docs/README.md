# docs/

Drop a dashboard screenshot here as `dashboard.png` and the project README
will pick it up automatically. Recommended capture flow:

1. `npm run start:all`
2. Open http://localhost:3000
3. Run a sample query (the RAG one in the README example works well)
4. Screenshot the page (Win+Shift+S on Windows) and save to `docs/dashboard.png`
5. `git add docs/dashboard.png && git commit -m "docs: add dashboard screenshot" && git push`

Optional: an animated GIF works too if you save it as `dashboard.png` (some
markdown viewers won't animate, but GitHub does).
